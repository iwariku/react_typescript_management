## 概要
本リポジトリは、React と TypeScript を用いて作成したユーザー管理アプリです。 型定義を活用し、ユーザー情報の一覧表示・追加・ソート機能を実装しています。

## 使用技術
- React 19.2.4
- TypeScript 5.9.3
- Vite 8.0.1
- Bootstrap 5.3.8

## 機能一覧
- ユーザー情報の一覧表示（タブで表示内容を切り替え可能）
- ユーザー新規作成機能
- ソート機能
